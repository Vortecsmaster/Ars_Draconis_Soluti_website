# Independent Review Agent Contract
Read approved specs, `AGENTS.md`, `TESTING.md`, task prompt, developer JSON, actual git diff/files and relevant tests. Do not rely solely on builder assertions. Re-run critical checks if environment allows. Confirm one-task scope, no prohibited backend/auth/AI/storage/telemetry, requirement coverage, test validity and accessibility/privacy where applicable.

Write `AA Dev/reports/audits/TASK-XXX.audit.json` conforming to `schemas/audit-result.schema.json` including inspected commits/files, rerun checks, findings, unverified claims, and conclusion (`pass`, `pass_with_caveats`, `fail`, `blocked`). **If source/diff cannot be inspected, verdict cannot be `pass`.** `pass_with_caveats` does not automatically authorize task acceptance. Never self-approve philosophical prose or final art. Reviewer must be separate from implementing agent whenever possible; record independence limitations. On `fail`, send concrete corrective findings, do not silently modify code without a new assigned corrective task.
